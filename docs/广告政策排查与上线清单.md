# 译想官网：广告政策排查与上线说明

检查日期：2026 年 11 月 6 日。范围为原官网公开页面、本地代码与构建产物。未登录 Google Ads、Search Console、WordPress 后台、DNS 或下载服务器，未扫描客户端安装包。

## 结论与边界

本次重建解决官网可控的外部依赖、内容透明度、链接和页面结构问题。不能据此确定 Google 报错的根因，也不能承诺恢复投放。Google 的恶意软件规则覆盖网站托管或链接的软件；删掉下载按钮不能替代客户端整改。

不要向广告审核系统和普通访客展示不同内容，不按来源、IP、设备或爬虫身份切换页面，不用换域名或隐藏入口来掩盖问题。此版本向所有访客提供同一份静态页面。

## 上线前仍需完成

1. **查明具体判定。** 在 Google Ads 政策详情中记录实际违规类型、完整最终落地 URL、可疑域名和示例。不要把“恶意软件”“被侵网站”与文案问题混为一谈。
2. **检查账号侧报告。** 在 Search Console 查看“安全问题”“人工处置”，并查看 Safe Browsing 的站点状态。本次没有账号访问权限，未代查这些报告。
3. **清理原环境。** 备份后检查 WordPress 主题、插件、管理员、定时任务、上传目录、数据库注入和重定向规则；删除后门并修补入口。切换静态站后，确保旧后台、旧文件、旧落地页不再通过其他路径暴露；更换已泄露凭据。
4. **核对 DNS/CDN。** 检查所有 A、AAAA、CNAME、CDN 规则、其他子域、HTTP/HTTPS、www/非 www 版本及缓存。不应出现某些地区或设备仍访问旧站的情况。推荐统一 HTTPS，并在域名/CDN 层将非 www 永久跳转到 www，保留路径和查询参数。
5. **扫描安装包与更新链。** 检查实际发布文件、更新器、下载服务器及所有跳转目标；核对签名证书、签名时间、发布者、macOS 公证、权限和捆绑组件。确认可正常卸载、无隐蔽行为；对误报保留扫描结果与签名证据，联系相应检测方核实。EV 签名不等于无恶意软件。
6. **核对实际数据行为。** 明确翻译文本、语音、日志、账户和本地缓存的处理方式、保存期限、删除流程、第三方引擎以及跨境处理安排。原软件条款只是迁移，未替业务或法律人员认证其准确性。
7. **核对主体和交易信息。** 公司、地址、备案、客服、价格、体验积分、退款及引擎可用性来自原官网，需运营方确认仍然有效。只有在信息真实、软件和下载链已处理后再开放下载。
8. **发布并复核。** 部署新站，检查生产响应头、全部页面、404、重定向、移动端、二维码和站点地图。不要把本地检查当作生产域名已清理。
9. **申请复审。** 按账号实际状态在 Ads 或 Search Console 提交真实、具体的整改材料，列明问题、处理时间、清理范围与安装包证据。不要声称 Google 已认证，也不要保证复审结果。

## 当前下载和视频配置

根据用户明确要求，`src/config/downloads.ts` 中四个原站下载地址均已启用。按钮要求 `enabled: true` 且 URL 为官方 HTTPS 地址；版本、签名、大小、发布日期和 SHA-256 为可选的真实信息，没有数据时不显示。此校验不等于软件安全扫描。本次 HEAD 检查四个地址均返回 200，没有下载或运行安装包。

首页原站的四段视频已恢复，MP4 地址、原 ID 和本地封面在 `src/config/videos.ts` 维护。使用浏览器原生 video，已删除原保利威 SDK 与中间播放页；响应头仅开放原 CDN 的媒体请求。四个 MP4 文件地址均返回 200、类型为 video/mp4，真实浏览器播放仍待验收。

后续可使用 `Get-FileHash -Algorithm SHA256 -LiteralPath <文件路径>` 与 `Get-AuthenticodeSignature -LiteralPath <文件路径>` 检查实际 Windows 安装文件；macOS 请核对 Developer ID 和公证结果。检查结果应真实记录，不以按钮开放状态代替核验。
